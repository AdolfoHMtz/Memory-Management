# 🧠 Simulador de Gestión de Memoria — Particiones

Simulador interactivo para la materia **Sistemas Operativos**. Muestra cómo el sistema operativo asigna memoria a los procesos con **particiones fijas** y **particiones dinámicas**, y calcula la fragmentación en cada paso.

## Funciones

- **Particiones dinámicas** con algoritmos **First Fit** y **Best Fit**.
- **Particiones fijas** configurables a mano.
- Agregar y terminar procesos, con **cola de espera** (FIFO estricta o flexible).
- **Compactación** de memoria.
- Métricas en vivo: memoria usada y libre, **fragmentación interna y externa** y desperdicio.
- Historial de capturas para revisar cada paso.

> Ver también: [Simulador de Paginación](https://github.com/AdolfoHMtz/Memory-Management-Pagination).

## Cómo ejecutarlo

```bash
npm install
npm run dev
```
